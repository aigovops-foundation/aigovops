**Ten minutes. Nothing installed. The whole practice in miniature.**
Status: **decide** — this kit describes what ships in P0 (days 1–30) if PRD v3 is approved.

## Who arrives here

Anyone. The manager trying to govern AI agents. A program officer. A student. A compliance lead who does
not read YAML. An engineer taking a first look. You do not need an agent, a repo, or an account.

## What you practise

All five parts, once each:

| Part | What you do on the Gate Check page | Tool |
|---|---|---|
| **Declare** | Write one rule in the rule box: an action, a tier, a decision (see `policy.yaml` beside this file — three lines) | Umbrella's vocabulary |
| **Decide** | Propose one action — the default scenario is a grant-drafting agent trying to send an email — and watch the gate answer: allow, constrain, hold, or deny | Beacon, in the browser |
| **Prove** | Download `bundle-<hash>.zip`. Inside is the signed receipt and `VERIFY.md`. It contains no payload — only hashes | Beacon, in the browser |
| **Read** | Click your lens — engineer, compliance, auditor, regulator — and read the same receipt four ways | Lantern, rendered in the page |
| **Return** | Your bundle hash goes on your Gate Card. The page's last line: *Bring it Thursday 09:00 — the first five minutes are for receipts.* | the Community |

## Take-home

`bundle-<hash>.zip` with `VERIFY.md`. It verifies with the level 400 offline verifier — same spec, same
fixtures. There is no demo-only schema.

## The return

You show the receipt to another person on Thursday. That is the level. A host marks it, and you are a
100. A download without a Thursday is not a 100 yet.
