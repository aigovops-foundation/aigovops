# Contributing to AiGovOps Practice

Three doors in, the same as every Foundation repo.

**Use it.** Do a worksheet. Where a step was unclear, too long, or did not work, open an issue with the level, the step number and what happened. That is contribution.

**Add to it.** Send a PR. Worksheets follow the shape in `docs/MEMBER-ACTIVITIES.md`: one real case from the corpus (cite the `VH-` number), all four gates, one signed artifact, one return, and both paths — plain words and code — to the same receipt. Each step is marked *live* or *fall*; never promise a command that does not exist yet. Practitioners' policies go under `catalog/<your-system>/`.

**Steward it.** A 400 reviews policy PRs (a policy change is a governed event). Spec-level questions go to the OVERT steward first — see `docs/GLACIS-ALIGNMENT.md`.

Apache-2.0. Sign your commits with the DCO (`git commit -s`). Be kind on Thursday.
