# The journey — how it all works together

One loop, drawn from the member's side. Wren is at every arrow. No step needs an account until the
person wants a mark, and no step needs code unless the person chooses the code path.

```
  a story · a post · a friend · the Camp · a search
        │
        ▼
  THE DOOR  — the site's home, the Community page, or Ask Wren on any page
        │   "Trust the data, not the vibes. Sit down; what do you have?"
        ▼
  THE WREN CARD  — five questions, three minutes, no account
        │   level · path (plain words / code / both) · your lens · your Thursday · who you'll show
        ▼
  THE WORKSHEET  — one hour or less; every step live or fall; a "no one left behind" table at the end
        │   100 Begin → 200 Retrofit → 300 Hold → 400 Prove · each on a real case · both paths
        ▼
  THE RECEIPT  — the Gate Check (100), a bundle (200), a coverage number (300), a verification (400)
        │   zero-egress: hashes and dates, never content
        ▼
  THURSDAY  — first five minutes are for receipts; Ken hosts until a 400 does
        │   you show it to a person; a host marks it; the mark is a receipt on the ledger
        ▼
  THE LETTER  — Tuesday: loops closed and marks by level, no names; the countdown to 2 Dec 2027
        │
        └──▶ next level, or host — and a friend brought to the door
```

## The objects that hold it together

| Object | Made at | Carries | Never carries |
|---|---|---|---|
| **Wren Card** | the door | level, path, lens, Thursday, who | your name until you choose; any content |
| **Gate Card** | the Gate Check | verdict, gaps, bundle hash | anything you answered |
| **Receipt / bundle** | the worksheet's *prove* step | hashes, decision, tier, policy hash, key id | prompts, outputs, payloads, personal data |
| **Mark** | Thursday, by a host | `practice.mark`, level, host key, date | who you are, unless you show it |
| **The Letter line** | Tuesday | counts by level | identities |

## The rules that keep it simple

1. **One name at the door: Wren.** One surface: Ask Wren. Jeeves stays in the runbooks.
2. **One next step, one Thursday.** Every message, page and card ends the same way.
3. **Two paths, one receipt.** Plain words or code — byte-identical results, marked the same.
4. **Ten-minute version of everything.** Every worksheet names the three steps that still produce a receipt.
5. **"I don't know yet" is always an answer,** and it always pairs you with someone.
6. **Nothing decides but the gate; nobody marks but a host.** Wren carries; she does not judge.
7. **Nobody is behind.** Every worksheet has the *no one left behind* table: no computer, phone only, Spanish, ten minutes, no Thursday, no agent, no code, no policy words.
