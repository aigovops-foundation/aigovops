# Thursdays — one file per Thursday, written by the host

After the call, the host spends ten minutes on one file here: `YYYY-MM-DD.md` (the Thursday's date,
Pacific). It is the recap thread made durable, and it is what next Tuesday's story is drafted from —
the Monday keeper reads the newest file, counts the mark lines by level, and writes a story into the
site's `content/stories/` for the coming Tuesday, ahead of the queued corpus case. No file, no story
from Thursday; the corpus case goes instead. Nothing here is a mark until a host writes it.

Copy `_TEMPLATE.md`, fill it, commit on main (the GitHub web editor is fine: open the folder, "Add
file", paste, commit). Keep it short. Names only with permission; "a member" is always allowed.
