AiGovOps Foundation · Plain-language terms

Glossary

Short definitions for the terms used across the Foundation’s tools and practice.

OVERT
An open standard for independently verifiable runtime evidence.
Beacon
An OVERT-conformant runtime that produces signed, verifiable receipts of AI decisions.
Receipt
Signed, verifiable evidence of an AI decision.
Gate Check
A ten-minute questionnaire that produces an audit plan.
Gate
A decision point in the Foundation’s four-gate governance framework.
Policy as code
Governance policies expressed as versioned, tested code before deployment.
Practice
Four one-hour levels with worksheets and a manifesto.
Library
One hundred verified AI-harm cases mapped to NIST AI RMF, EU AI Act, ISO/IEC 42001, and OWASP.
Umbrella
A Foundation tool that declares policies.
Lantern
A Foundation tool that reads evidence.
AiGovOps
Treating AI governance like code: versioned, tested, and verifiable before deployment.
