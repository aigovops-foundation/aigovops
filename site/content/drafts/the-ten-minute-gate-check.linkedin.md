The ten-minute Gate Check — is this AI agent ready to run?

We built the AiGovOps community around one loop: learn a little, try it, produce evidence, gain confidence. The first pass through that loop should take ten minutes and leave you holding something. So here is the first thing you can hold: the Gate Check. Ten questions about an AI agent you are being asked to say yes or no to. Each one is a yes or a no, and each one names the evidence you would point at — a scope statement with an owner's name on it, the log you opened yourself this week, the name of the person who last turned it off. There is no "maybe" on the page. A maybe is a no with homework.
