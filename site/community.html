Ways to contribute

Every contribution — code, documentation, feedback, or funding — matters.

💻
Write code
Pick an open issue on Beacon, Lantern, or any foundation repo. First-time contributors welcome.
📖
Improve docs
Documentation is governance. Help make the OVERT 1.0 spec and tool guides clearer for new practitioners.
⚖️
Map frameworks
Know a regulation not in our frameworks explorer? Open a PR to add it — 40+ frameworks and growing.
🌍
Translate
The site has EN/ES i18n support. Help extend to additional languages — especially for underserved markets.
📣
Spread the word
Star the repos on GitHub, share the newsletter, or cite OVERT 1.0 in your own governance work.
💚
Fund the standard
GitHub Sponsors and Open Collective. Even a coffee keeps the CI running.
